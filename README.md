# Homebrew tap for dispatch-ai

Homebrew formulae for [dispatch-ai-labs/dispatch-ai](https://github.com/dispatch-ai-labs/dispatch-ai).

## Install

```bash
brew tap dispatch-ai-labs/dispatch-ai
brew install dispatch-ai

Then:

dispatch --version

What's here

┌─────────────┬───────────────────────────────────────────────────────────────────────────────┐
│   Formula   │                                   Installs                                    │
├─────────────┼───────────────────────────────────────────────────────────────────────────────┤
│ dispatch-ai │ The dispatch CLI — a Pattern 3 autonomous coding tool with a strict verifier. │
└─────────────┴───────────────────────────────────────────────────────────────────────────────┘

Supported platforms: macOS (arm64, x86_64), Linux (arm64, x86_64).

Notes

Formula/dispatch-ai.rb is regenerated on every release by the workflow in the main repo. Do not edit it directly — changes will be overwritten on the next release. File issues and PRs against dispatch-ai-labs/dispatch-ai instead.

License

Formulae are Apache 2.0, same as the project they install.
```
